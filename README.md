# SaleScout — демо-сервис управления ценами

SaleScout помогает продавцу Kaspi следить за ценами конкурентов и рассчитывать цену в заданном диапазоне. В этой версии доступны регистрация и вход, личный демо-каталог, создание/редактирование/удаление товаров, список конкурентов, пересчёт цен, история, настройки профиля и раздел помощи.

**Важно:** это рабочий учебный прототип, а не подключение к настоящему Kaspi. Пересчёт сохраняет результат только в демо-аккаунте. Данные аккаунтов находятся в `.data/accounts.json`, пароли хранятся в виде хешей. Для публичного запуска с постоянными аккаунтами JSON-хранилище нужно заменить на постоянную базу данных.

## Локальный запуск

Требуется Node.js 20 или новее и npm.

```bash
npm install
npm run dev
```

Vite покажет адрес веб-страницы (обычно `http://localhost:5173`). Express API по умолчанию работает на порту `3001`. Если порт API уже занят, укажи свободный порт:

```powershell
$env:API_PORT = "3002"
npm run dev
```

Страница регистрации открывается первой. После регистрации для аккаунта создаются демонстрационные товары. При следующем входе товары и история берутся с сервера.

## Production-сборка

```bash
npm run build
$env:AUTH_SECRET = "replace-with-a-long-random-secret"
$env:NODE_ENV = "production"
npm start
```

В production Express обслуживает собранный фронтенд из `dist`. На платформе хостинга используй команды сборки `npm install && npm run build` и запуска `npm start`, переменные `NODE_ENV=production` и `AUTH_SECRET`, а также постоянное хранилище для `.data`. Не публикуй настоящий сайт, пока вместо файла `.data/accounts.json` не подключена постоянная база данных.

## API

- `POST /api/auth/register` — создать аккаунт.
- `POST /api/auth/login` — войти.
- `GET /api/products`, `POST /api/products`, `PUT /api/products/:sku`, `DELETE /api/products/:sku` — каталог аккаунта (нужен Bearer-токен).
- `POST /api/reprice` — пересчитать и сохранить демо-цены (нужен Bearer-токен).
- `GET /api/history` — история пересчётов.
- `POST /reprice` — endpoint тестового задания: принимает `Product[]` и возвращает `PriceResult[]` без авторизации.

## Расчёт цены

`src/pricing.ts` экспортирует чистую функцию `calculatePrice(product)`. Она игнорирует конкурентов без наличия, округляет `best - step` вниз и ограничивает результат `minPrice` и `maxPrice`. `myPrice` не влияет на расчёт и возвращается как `oldPrice`.

Тесты алгоритма находятся в `src/pricing.test.ts` и запускаются командой `npm test`.
